   - 检查引用链接有效性

## 🤝 贡献指南

### 如何贡献文档

1. **Fork项目**
   ```bash
   git clone https://github.com/opengm-ca/opengm-ca.git
   ```

2. **创建文档**
   - 遵循文档模板
   - 使用Markdown格式
   - 添加必要的图表和示例

3. **提交文档**
   ```bash
   git add doc/YOUR_DOCUMENT.md
   git commit -m "docs: 添加XXX文档"
   git push origin your-branch
   ```

4. **创建Pull Request**
   - 描述文档内容和目的
   - 等待审核和合并

### 文档审核标准

- ✅ 内容准确无误
- ✅ 格式规范统一
- ✅ 语言流畅清晰
- ✅ 引用链接有效
- ✅ 包含必要示例
